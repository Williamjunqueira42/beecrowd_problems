# Problema 1021
[Link do problema.](https://judge.beecrowd.com/pt/problems/view/1021)

Uma abordagem simples é verificar, em cima do montante, quantas notas eu consigo tirar sem passar do valor (o que representa a parte inteira da divisão entre o montante e o valor das notas). Fazendo isso com todas as notas, sempre, a cada passo, tirando do montante as notas possíveis 
 ```c
 int main(){
	 int notas100, notas50 ... notas2;
	 int moedas1, moedas50 ... moedas1;
	 double montante = ...;
	 // P/ notas de 100
	 if (montante / 100 >= 1) {
		 //como notas100 é um inteira, notas100 só pega a parte inteira da divisão montante / 100.
		 notas100 = montante / 100;
		 montante -= notas100*100;
	}
	.
	.
	.
	// P/ notas de 2
	if (montante / 2 >= 1) {
	notas2 = montante / 2;
	montante -= notas2*2;
	}

	return 0;

}
 ```
e depois repetindo o mesmo processo com as moedas.

Entretando podemos ter problemas ao repetir essa lógica com as moedas, já que estes, estão sendo representados como valores flutuantes.

Certos valores decimais, como 0.10 e 0.30, **não são passíveis de representação exata com um número finito de bits**, já que são dízimas binárias. Assim, o valor armazenado na memória é uma aproximação, o que pode gerar determinados problemas, já que o valor guardado pode ser ligeiramente diferente do valor decimal esperado.

Por exemplo, digamos que, após passar por todas as notas e pelas moedas de 0.50 e 0.25, você tenha um montante esperado de 0.30. Como já dito, o valor guardado na memória pode diferir ligeiramente de 0.30 e ser algo mais próximo de 0.299999999999... Agora, ao dividir esse valor por 0.10, que também é uma aproximação, o resultado pode acabar sendo ligeiramente menor que 3, e, ao tentar pegar a parte inteira, você teria uma quantidade de moedas de 10 centavos igual a 2 e não 3.

Por isso, nesse tipo de problema, em que é melhor trabalhar somente com inteiros, como a menor unidade é de 0.01 reais (1 centavo), vamos converter todos os valores para centavos.

 ```c
 #include <math.h>
 int main() {
	int notas100, notas50 ... notas2;
	int moedas1, moedas50 ... moedas1;
	double montante = ...;
	int montante_centavos = round(montante*100) 
	// P/ notas de 100
	notas100 = montante_centavos / 10000; // Se essa divisão for menor que 1, notas 100 vai ser igual a 0
	montante_centavos -= 10000*notas100;
	.
	.
	.
	// P/ moedas de 5 centavos
	moedas5 = montante_centavos / 5;
	montante_centavos -= moedas*5;
	
	moedas1 = montante_centavos;
	return 0;
}
  ```
